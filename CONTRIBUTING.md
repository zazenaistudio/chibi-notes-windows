# Contribuir a Chibi Notes

Gracias por ayudar a mejorar Chibi Notes.

## Errores y sugerencias

Puedes abrir una incidencia para comunicar:

- errores reproducibles;
- problemas de instalación o compilación;
- mejoras de accesibilidad o experiencia de usuario;
- propuestas de nuevas funciones.

Incluye la versión de Windows, la versión de Chibi Notes, los pasos para reproducir el problema y, cuando sea posible, capturas o registros sin datos personales.

## Cambios de código

Chibi Notes se publica bajo una licencia propietaria de uso personal. Antes de enviar una traducción, integración, modificación extensa o pull request, solicita autorización a Zazen AI Studio mediante una incidencia. La aceptación de una propuesta no concede permiso para redistribuir versiones modificadas o reutilizar los recursos visuales del proyecto.

## Recursos visuales

Las mascotas, fondos, iconos, ilustraciones, sonidos, logotipos y elementos de marca no pueden extraerse ni reutilizarse en otros proyectos sin autorización escrita.

Consulta [LICENSE](LICENSE) antes de participar.
